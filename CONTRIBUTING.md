# Contributing to BOB

Thank you for improving BOB. Changes should preserve scientific provenance, authorization boundaries, and reproducible deployment.

1. Open or reference an issue describing the behavior and acceptance criteria.
2. Create a focused branch and add tests that fail before the change.
3. Run the checks in [docs/development.md](docs/development.md).
4. Open a pull request using the template and describe migrations, API compatibility, and security effects.

Do not submit credentials, identifiable research data, private instrument files, or production database extracts. Synthetic fixtures belong in `bob/fixtures.py` or the tests.
